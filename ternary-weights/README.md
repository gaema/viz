# ternary weights — a multiply becomes an add

> **▶ [Open this demo](index.html)** · [all demos →](../index.html)

The weights are 0.90, 0.20, −0.80, 0.10, and −0.40. Each becomes −1, 0, or +1 by rounding weight/scale into that set, and clipping.

The reconstruction is the code times the printed scale. The full dot is the sum of the printed weights. The ternary dot is the sum of the printed reconstructions. At scale 0.50 the codes are 1, 0, −1, 0, −1, three of the five weights survive, and the dots are 0.00 and −0.50.
