sage attention — low-precision scores

Exact attention keeps every score at full precision. Rounding each score row to eight-bit integers, against that row's own largest entry, moves the mixed output. A row that is already zero stays exact, because every code lands on the grid. The saving is the bytes moved for the scores. The cost is that the attention is no longer the same numbers.

Keys and values are fixed. The query-scale slider changes the query. The score row is quantized to int8 against its own maximum and compared with exact attention. At the default scale the error is above zero. All-zero keys stay exact.
