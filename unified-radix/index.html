unified radix — one match, three kinds of state

Some models do not keep one kind of memory. A layer that looks at the whole prefix stores a note per word, a layer that only looks at a recent window stores just that window, and a recurrent layer stores a single running summary. One shared prefix can hand back all three from the same match: every matched word for the full layers, only the tail that still fits the window, and one summary, which is usable only when the match is longer than nothing. A match shorter than the window cannot invent extra window notes that were never stored.

One matched prefix feeds three stores.

Full-attention KV covers every matched token. Sliding-window KV covers min(match, window) tokens, the tail of the match, and never tokens the match did not include. A recurrent layer reuses one checkpoint, and only when the match is longer than nothing. Turning that layer off leaves the checkpoint at zero. An empty match reuses none of the three.
