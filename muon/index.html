muon — orthogonalise the matrix update

Most optimizers scale each number on its own. Muon treats a two-dimensional gradient as a matrix and pulls its singular values toward one, so every direction of the update has the same strength. The iteration does not apply to an embedding table, the output head, or a per-channel gain, so a real recipe runs this update beside a second optimizer.

A matrix gradient is passed through Newton–Schulz. Drag the step count and the singular values move toward 1. Embeddings, the output head, and gains are marked as staying on a second optimizer.
