kv fabric — one pool across machines

Each machine can remember the prefixes it has already read, but a request only gets that memory if it is sent to the machine that holds it. Send the same opening to a different machine and the work is done again. A shared pool keeps one copy the whole cluster can see, so the second machine finds the prefix even though it never read it itself. One machine makes the two schemes identical. Several machines, and the same opening repeated on different ones, is where the shared pool pulls ahead.

Each arrival of prefix p in wave r is assigned to machine (p + r) mod machines.

A private cache hits only when that machine has already seen the prefix. A shared pool hits when any machine has. The percent on each bar is 100 × hits / requests from the two counts printed beside it. One machine makes the two counts equal. A later wave on a different machine is a shared hit and a private miss.
