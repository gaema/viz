transformer-block -- one full pre-norm block

A language model is built by stacking one repeating unit, and this is that unit. A word's numbers are rescaled to a standard size, sent through attention so that words can pull information from each other, and the result is added back onto the running total; then rescaled again, sent through the small per-word network where the model's knowledge sits, and added back again. That is one whole layer. A modern language model is this same unit stacked several dozen times with different numbers in each copy, which is why models grow mostly by getting deeper rather than by acquiring new kinds of part.

Interactive page: a whole transformer block end to end -- x -> RMSNorm -> Attention -> + -> RMSNorm -> MLP -> + -> out -- showing the residual spine and the two sublayer branches that read it (via norm) and add back. Anchor: the block is the unit the per-attribute A1-A12 pages assemble into; Family C capstone.

What it shows

A token sequence x [N×D] flows along a residual spine. Two sublayers branch off it and add back:

  • Attention: a = Attn(RMSNorm(x)), then h1 = x + a.
  • MLP (SwiGLU): m = MLP(RMSNorm(h1)), then out = h1 + m.

This is pre-norm (norm sits on the read branch; the spine itself is never normalized -- the identity highway from residual-stream). Every tensor is really computed (Q/K/V, causal softmax, SwiGLU); the sublayer internals live in their own pages (scaled-dot-attention, mlp-gated, normalization).

Step the transport through the six stages (norm1 -> attn -> add -> norm2 -> mlp -> add); drag any x cell to steer the input and watch the whole block recompute; hover any cell for its value + stage.
