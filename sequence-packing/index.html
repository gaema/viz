sequence-packing — many documents, one row

Training rarely feeds one document per row. Several short documents are laid end to end in a single row so the hardware stays full. A block-diagonal mask lets each token read only inside its own document. Leave that mask open and the run still converges, while the model has learned to read across the boundary between two unrelated documents.

Interactive page: packing several short sequences into one fixed-width training row, and the block-diagonal mask that keeps the packed documents independent. Anchor: A3 attention pattern (Family B).

What it shows

Three documents of lengths [2, 3, 1] share one row of six tokens, drawn as a 6×6 attention mask. In block-diagonal mode a cell [i,j] is allowed only when tokens i and j belong to the same document — the mask is a staircase of square blocks along the diagonal and the cross-document pair count is 0, so each document trains as if it were alone in the row. Switch to full mode: the mask is true everywhere, training still runs, the count becomes positive — every off-block pair is a token quietly reading context across a document boundary. The block outlines show the packing structure; a dashed outline marks an allowed cross-document cell. Hover any cell for the per-pair verdict.

The mask and the pair count come from math.js (packMask, crossDocumentPairs), checked by math.test.mjs.
